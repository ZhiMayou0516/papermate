# PaperMate Lit Assistant

一个面向科研阅读流程的轻量级本地文献助手，用于完成论文检索、文献收藏、摘要阅读、阅读卡片整理、笔记管理、文献矩阵导出，以及学术词汇学习。

PaperMate 并不是为了替代 Zotero、EndNote 这类完整文献管理器，而是更聚焦于科研阅读中最容易混乱的一段流程：从“搜到一堆文献”到“判断哪些值得细读”，再到“沉淀成可复用的阅读笔记、综述素材和术语积累”。

## 项目特点

- **多来源文献检索**：支持 Semantic Scholar、arXiv、PubMed、bioRxiv 等来源
- **本地文献库管理**：基于 SQLite 保存文献信息、阅读状态、标签和笔记
- **重复文献识别**：保存文献时尽量避免重复收录
- **文献初筛辅助**：根据标题、摘要、关键词等信息生成文献类型、优先级、相关性评分和阅读建议
- **项目化分类管理**：支持按研究方向、项目、主题、状态、年份、期刊、引用量等条件筛选
- **摘要阅读与翻译**：支持摘要查看、可选机器翻译和中英文对照阅读
- **本地 PDF 附件管理**：可为文献绑定本地 PDF 文件，方便集中整理
- **结构化阅读卡片**：围绕研究问题、方法、数据、结果、局限性、可复用观点等维度进行记录
- **自由笔记系统**：支持为每篇文献添加开放式阅读笔记
- **文献矩阵导出**：将多篇论文按方法、数据集、结论、局限性等字段导出，便于横向比较
- **周阅读报告导出**：自动汇总阶段性阅读进展
- **学术词汇本**：从真实摘要语境中积累专业词汇、例句、来源和个人备注
- **间隔复习训练**：提供 Again / Hard / Good / Easy 等复习按钮，用于词汇巩固
- **摘要翻译训练**：基于文献摘要句子进行英文阅读和翻译训练
- **可视化仪表盘**：展示文献数量、阅读状态、优先级分布、年份分布、词汇复习任务等信息

## 使用场景

PaperMate 适合以下类型的科研阅读任务：

- 刚进入一个新方向，需要快速搜索和初筛文献
- 阅读论文时希望把“摘要、方法、数据、结论、局限性”整理成统一格式
- 写综述、开题报告或项目报告前，需要建立文献对比矩阵
- 希望把文献中反复出现的专业词汇整理成自己的学术词汇本
- 希望在本地保存文献笔记，不依赖复杂的云端系统

## 工作流程

1. 在搜索页面输入关键词，选择文献来源进行检索。
2. 查看题目、作者、年份、期刊、摘要和链接等信息。
3. 将有价值的文献保存到本地文献库。
4. 系统根据摘要和关键词生成初步分类、优先级、相关性评分和阅读建议。
5. 在文献库中按项目、类别、状态、优先级、年份等条件筛选论文。
6. 进入阅读页面，查看摘要、绑定 PDF、翻译文本并记录笔记。
7. 对重点文献填写结构化阅读卡片。
8. 将不认识的学术词汇加入词汇本。
9. 使用间隔复习模块复习词汇，或使用摘要翻译训练模块练习学术英语阅读。
10. 导出 Markdown 或 CSV 格式的阅读卡片、文献矩阵和阶段性报告。

## 功能模块

### 1. 文献检索

支持从多个开放文献来源检索论文，并返回标题、作者、年份、摘要、DOI、期刊、引用量、链接等信息。检索结果可以直接保存到本地数据库。

### 2. 文献库

文献库用于统一管理已保存论文。每条文献可以包含：

- 标题、作者、年份、期刊
- 摘要、DOI、URL
- 项目、类别、标签
- 阅读状态、优先级、文献类型
- 相关性评分、个人备注
- 本地 PDF 路径

### 3. 阅读器

阅读器用于对单篇文献进行深入整理，包括摘要阅读、机器翻译、本地 PDF 绑定、自由笔记和结构化阅读卡片。

结构化阅读卡片包括：

- 研究问题
- 方法与模型
- 数据来源与数据规模
- 主要结果
- 创新点
- 局限性
- 可复用观点
- 可引用位置
- 个人判断

### 4. 阅读笔记

支持为每篇文献记录多条自由笔记，用于保存阅读过程中的想法、疑问、复现思路和写作素材。

### 5. 文献矩阵

可以将多篇文献整理为横向对比表，便于比较不同论文的研究对象、方法、数据集、结论和不足。

### 6. 周阅读报告

可以导出阶段性阅读报告，帮助回顾最近阅读了哪些论文、形成了哪些卡片、积累了哪些词汇和笔记。

### 7. 学术词汇本

词汇本用于保存阅读文献时遇到的专业词汇。每个词条可以记录：

- 单词或短语
- 中文含义
- 来源论文
- 原文语境
- 例句
- 难度等级
- 个人备注
- 下次复习时间

### 8. 词汇复习

复习模块提供简单的间隔复习机制。用户可以根据记忆情况选择 Again、Hard、Good 或 Easy，系统会更新下一次复习时间。

### 9. 摘要翻译训练

从文献摘要中抽取句子，用于练习英文学术句子的理解和翻译。适合在阅读文献的同时积累专业表达。

### 10. 仪表盘

仪表盘用于查看整体阅读进度，包括：

- 文献总数
- 已读文献数量
- 高优先级文献数量
- 阅读卡片数量
- 笔记数量
- 词汇数量
- 待复习词汇数量
- 项目分布
- 文献类型分布
- 年份分布


## 技术栈

- **开发语言**：Python
- **前端界面**：Streamlit
- **本地数据库**：SQLite
- **数据处理**：pandas
- **可视化**：Plotly
- **文献检索接口**：Semantic Scholar、arXiv、PubMed、Europe PMC / bioRxiv
- **翻译模块**：deep-translator
- **导出格式**：Markdown、CSV

## 安装与运行

### 1. 克隆项目

```bash
git clone https://github.com/your-username/papermate-lit-assistant-v4.git
cd papermate-lit-assistant-v3
```

### 2. 创建虚拟环境

```bash
python -m venv .venv
```

激活虚拟环境：

```bash
# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate
```

### 3. 安装依赖

```bash
pip install -r requirements.txt
```

### 4. 启动应用

```bash
streamlit run app.py
```

启动后，在浏览器中打开终端显示的本地地址，通常为：

```text
http://localhost:8501
```

## 数据保存位置

PaperMate 默认将本地数据库保存到：

```text
data/papermate.db
```

本地 PDF 附件保存到：

```text
data/pdfs/
```

项目采用 local-first 的设计思路。文献记录、阅读笔记、词汇数据和 PDF 路径默认保存在本地，不依赖远程数据库。

## 文献来源说明

| 来源 | 用途 |
|---|---|
| Semantic Scholar | 通用学术论文检索 |
| arXiv | 预印本检索，适合 AI、计算机、数学和交叉学科方向 |
| PubMed | 生物医学和生命科学文献检索 |
| bioRxiv | 生物学预印本文献检索 |

部分数据库没有稳定开放的免费公共 API，因此项目采用外部跳转或辅助检索的方式，而不是直接爬取受限内容。

## 设计思路

PaperMate 的核心目标是让科研阅读流程变得更清晰、更可复用。它不是单纯保存 PDF 文件，而是围绕“检索—初筛—阅读—记录—复习—导出”建立一个轻量工作流。

项目中的文献初筛、关键词识别和优先级判断主要使用规则启发式方法。这种方式虽然不如大型模型复杂，但优点是轻量、可解释、易修改，也更适合本地快速运行。

对于期刊影响因子、单位信息等可能涉及授权数据库的数据，项目提供可编辑字段，由用户自行补充，而不是爬取受限制来源。
